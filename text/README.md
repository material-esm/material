# Text Field

```html
<md-text-field label="Name" color="outlined"></md-text-field>

<md-text-field label="Email" color="filled"></md-text-field>

<md-text-field type="color" label="Theme Color" value="#6750a4"></md-text-field>
```

### Supported Types

- `text` (default)
- `textarea`
- `color`
- `date`
- `datetime-local`
- `email`
- `number`
- `password`
- `search`
- `tel`
- `time`
- `url`
